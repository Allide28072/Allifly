# Changelog

All notable changes to the Allifly 3D Space Explorer project.

## Core Engine
- Three.js scene with 60fps WebGL rendering

## Flight & Controls
- 6DOF flight model with banking roll physics and afterburner

## Worlds
- Procedural solar sector with explorable planetary surfaces

## Ships & Hangar
- Multiple spacecraft with upgradeable subsystems

## Missions
- Galactic mission system with rewards and progression

## Audio
- Procedural sound engine built on the Web Audio API

## UI & HUD
- Heads-up display, galaxy map and modal interfaces

## Mobile & PWA
- Touch controls and installable progressive web app

## Desktop
- Electron wrapper for standalone desktop builds

## Persistence
- Local save game storage for player progress

## Documentation
- README and technical documentation
